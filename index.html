库存预警规则

当前系统按每件商品自己的最小库存和最大库存判断“库存不足”与“库存过剩”，不再展示未生效的全局百分比和智能预测设置。

可在库存管理中新增或编辑商品时维护库存上下限；库存数量仍需通过进货、出货流程调整。

数据导出

数据导入

SYSTEM HANDBOOK

系统使用说明

按业务发生顺序建档，系统会自动校验前置数据并保护历史记录。

电脑端操作规范
第一次使用，从“公司管理”开始。 如果直接创建商品、进货、出货或对账单，系统会提示缺少的前置数据；选择“去创建”即可跳转到对应页面。

推荐建档顺序

从基础资料到业务单据，按以下顺序可避免数据缺失。

  1. 1公司维护我方开票与发货主体
  2. 2客户 / 供应商建立业务往来对象
  3. 3商品关联供应商并设置价格、库存上下限
  4. 4进货入库形成已确认流水并增加库存
  5. 5销售出库选择客户、商品，生成送货单并扣减库存
  6. 6对账与报表按已发生单据生成对账结果

日常进出货

库存数量以已确认的业务记录为准。

  • 进货：进入“库存管理”或“进出货管理”，点击“新增进货 / 商品”。选择已有商品可补货，输入新名称则会同时建档并入库。
  • 出货：点击“新增出货”，仅可选择有效且有库存的商品。
  • 销售送货单：选择公司、客户和商品，提交后自动扣减库存并生成出库流水。
  • 库存不足：先完成进货，再创建出货；系统不会允许库存变为负数。

对账单与状态

对账数据来源于已发生的进货或送货记录。

  • 客户对账：先有客户送货记录，再按公司、客户和日期范围创建。
  • 供应商对账：先有供应商进货记录，再选择对应期间生成。
  • 单据来源：草稿或作废记录不会进入新的对账范围。
  • 避免重复：已被有效对账单占用的来源单据不会再次计入。

资料停用与历史保护

有历史业务的数据不会被直接物理删除。

  • 未被引用：公司、客户、供应商或商品可以直接删除。
  • 已被引用：删除操作会改为“停用”，历史单据与流水保持不变。
  • 停用后：资料仍可在历史列表中查看，但不会出现在新增业务的选择框中。
  • 重新启用：公司、客户、供应商和商品均可通过编辑将状态恢复为“活跃”。

数据维护与备份

重要操作前先备份，减少误操作风险。

  • 导出：在“系统设置 → 数据备份”下载 JSON 备份文件。
  • 导入：导入会覆盖当前数据，操作前请再次导出最新备份。
  • 测试数据：“写入测试”仅用于演示；“清空数据”为不可恢复的危险操作。
  • 操作追溯：新增、编辑、停用和删除动作可在“日志系统”查看。

常见问题

遇到无法创建或选不到数据时，优先检查以下项目。

选择框里没有资料确认资料已经创建，并且状态为“活跃”。
无法创建出货确认已有客户、有效商品，并且商品当前库存大于 0。
对账单没有来源记录确认对应期间已有进货或送货记录，且尚未被其他有效对账单占用。
误停用了资料进入对应管理页面编辑资料，将状态恢复为“活跃”。
