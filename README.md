# 仓库库存管理系统

一个基于 `HTML + Tailwind + JavaScript` 的本地仓库库存管理演示系统，支持库存管理、进出货记录、供应商/客户/公司管理、日志查看和销售单出库。

## 启动方式

1. 安装 Node.js。
2. 在项目目录运行 `npm start`。
3. 打开终端输出的本地地址。

## 目录说明

- `index.html`: 主页面
- `js/script.js`: 主业务逻辑
- `js/sales-order.js`: 销售单逻辑
- `data/`: 默认数据文件
- `preview_server.js`: 本地预览与数据保存服务
